# 🍃 Projeto MongoDB

API desenvolvida em Java com Spring Boot para estudo de banco de dados NoSQL utilizando MongoDB.

O projeto demonstra operações CRUD e modelagem de documentos.

---

## 🚀 Tecnologias Utilizadas

- Java 21
- Spring Boot
  - Spring Web
  - Spring Data MongoDB
- MongoDB
- Maven

---

## 📚 Conceitos Aplicados

- Documento JSON
- @Document
- @Id
- Relacionamento entre documentos
- Consultas personalizadas
- DTO
- Camada de serviço

---

## 🏗 Estrutura

- domain
- repository
- service
- resource
- config

---

## ▶ Como Executar

1. Instalar e rodar MongoDB
2. Configurar conexão no application.properties
3. Executar aplicação
